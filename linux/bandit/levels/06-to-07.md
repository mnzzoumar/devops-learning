# Bandit 6 > 7: Searching by user, group and size

**Status:** Complete

## Solution

```bash
find / -size 33c -user bandit7 -group bandit6    # Find matching files across the server
find / -type f -size 33c -user bandit7 -group bandit6 -exec cat {} \; 2>/dev/null    # Print matching file contents while hiding permission errors
```
