# Bash Fundamentals

## What is Bash

Bash (Bourne Again Shell) is a command-line interpreter used to interact with operating systems. Scripting allows multiple commands to be combined into a single executable file, making repetitive tasks easier to automate.

## Scripting

A Bash script begins with a shebang to specify which interpreter executes the script:

```bash
#!/bin/bash
```

Scripts can be executed using:

```bash
bash script.sh      # Execute the script using Bash
```

Always remember to change executing permissions if you want to execute the script directly. This is where the shebang is necessary for interpretation.
